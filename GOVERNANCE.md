# Governance

LLM Gateway currently uses a maintainer-led governance model.

Maintainers set the roadmap, approve designs, review contributions, manage releases, resolve security reports, and decide when features or compatibility guarantees are ready. Decisions prioritize security, tenant isolation, operational safety, backward compatibility, and maintainability.

External feedback is welcome through issues. External code contributions require explicit prior maintainer approval as described in `CONTRIBUTING.md`. Public availability of the source does not imply that every proposed change will be accepted or reviewed.

Release authority, repository administration, branch protection, signing identities, package publishing, and security-advisory access remain restricted to designated maintainers. Governance may evolve as the maintainer and contributor community grows; material changes will be documented in this file.
