# Support

LLM Gateway is provided as open-source software without warranty or a support SLA.

- Use GitHub Issues for reproducible defects and clearly scoped feature proposals.
- Use the documentation and existing issues for configuration and operational questions.
- Follow `SECURITY.md` for vulnerabilities; never disclose them publicly.
- Do not include credentials, tokens, customer data, prompts, or provider responses in support material.

Maintainers respond on a best-effort basis and may close requests that are incomplete, outside the supported scope, or better handled by an upstream provider. Commercial support is not currently offered.
